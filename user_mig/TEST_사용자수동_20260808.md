# NOVA 사용자 수동(눈) 검증 체크리스트 — 2026-08-08

대상: `http://192.168.21.112:8600` (이미지 `nexus-web:injguard-20260808`)

**이 17건만 남았습니다.** 자동 검증 92건은 끝났고(PASS 89 / WARN 3 / FAIL 0),
각 항목의 **서버측 대응 검사는 모두 통과**했습니다. 즉 여기서 볼 것은
"API 는 맞는데 **화면이 그걸 제대로 보여주는가**" 뿐입니다.

기록법: 각 항목 앞 `[ ]` 를 `[P]`(통과) / `[F]`(실패) / `[-]`(해당없음) 으로 바꾸고,
F 면 무엇이 어떻게 보였는지 한 줄 적어 주세요. 그대로 xlsx 에 반영합니다.

> **왜 이걸 사람이 봐야 하나** — 서버가 옳은 값을 줘도 화면이 안 그리면 사용자에겐
> 고장입니다. 실제로 이 리포에서 "API 는 200 인데 프런트가 안 뿌린" 사고가 있었습니다.

## A. 사이드바 (5건)

준비: 대화 3개 이상 만들어 두세요(아무 질문이나).

- [P] **A1 핀 고정 렌더**
  대화 목록에서 아래쪽 대화 하나에 📍(핀)을 누른다.
  **합격**: 그 대화가 목록 **맨 위로 이동**하고, 새로고침해도 위에 남는다.

- [P] **A2 이름변경 UI**
  대화의 ✎ 를 눌러 제목을 `테스트제목ABC` 로 바꾼다.
  **합격**: 목록에 즉시 반영되고, 새로고침 후에도 유지된다.

- [P] **A3 최근순 정렬**
  아래쪽에 있던(핀 없는) 대화에 메시지를 하나 보낸다.
  **합격**: 그 대화가 **핀 대화들 아래, 나머지 위**로 올라온다.
  **함정**: 순서가 매번 뒤죽박죽이면 실패(무작위 정렬 버그).

- [P] **A4 검색 UI**
  검색창에 앞서 보낸 메시지의 특징적인 단어를 2자 이상 입력한다.
  **합격**: 매치된 대화가 뜨고 **본문 일부(스니펫)** 가 보이며, 클릭하면 그 대화로 이동한다.
  1자만 입력하면 결과가 비어야 한다.

- [F] **A5 폴더 그룹**
  대화 2개를 📁 로 같은 폴더(`업무`)에 넣는다. 
  **합격**: 사이드바에 `업무` 그룹이 생기고 **접기/펴기**가 되며 **개수**가 표시된다.
  폴더를 해제하면 미분류로 돌아온다.
  CTRL 키를 누르고 두개의 대화 목록 선택해서 컨트롤하거나, 생성한 폴더에 드래그로 넣는게 안됨

## B. 렌더 (4건)

- [P] **B1 코드블록 복사 ★가장 중요**
  "파이썬으로 퀵소트 짜줘" → 코드블록의 **복사 버튼**을 누른 뒤 아무 곳에나 붙여넣기.
  **합격**: 코드가 실제로 붙여넣어진다.
  **★함정**: 지금 접속은 **HTTPS 가 아니라 HTTP** 다. 이 경우 브라우저의 클립보드 API 가
  막히므로 폴백(`execCommand`)이 돌아야 한다. 버튼이 "복사됨"이라고 표시만 하고
  **실제로는 안 붙여넣어지는 것이 전형적인 실패**다. 반드시 붙여넣기까지 해볼 것.

- [P] **B2 HTML 프리뷰**
  "간단한 HTML 페이지 하나 만들어줘. 제목과 버튼 하나." → 코드블록의 **▶미리보기**.
  **합격**: 옆/아래에 렌더된 화면이 뜬다.
  **확인**: 미리보기 안의 내용이 NOVA 화면 자체를 깨뜨리지 않는다(격리돼 있어야 함).

- [P] **B3 스트리밍 렌더**
  "인공지능의 역사를 자세히 설명해줘" 처럼 긴 답변을 요청한다.
  **합격**: 생성되는 동안 글자가 차오르고 **마크다운(제목·목록·굵게)이 실시간으로**
  정리돼 보인다. 완료 후에도 레이아웃이 흔들리지 않는다.
  **함정**: 생성 중에는 원시 `##`·`**` 가 그대로 보이다가 끝나고 확 바뀌면 실패.

- [P] **B4 문서/이미지 생성 표시**
  ① "빨간 사과 그려줘" ② "'테스트 보고서' 워드 문서 만들어줘"
  **합격**: ①은 이미지 썸네일이 화면에 뜨고, ②는 **다운로드 버튼**이 뜬다.
  버튼을 눌러 파일이 실제로 받아지는지까지 확인.

## D. 신기능 (5건)

- [P] **D1 커스텀 인스트럭션**
  설정에서 지시문을 `모든 답변 끝에 [확인됨] 을 붙여라` 로 저장 → 아무거나 질문.
  **합격**: 답변 끝에 `[확인됨]` 이 붙는다. 지시문을 **지우면 다시 안 붙는다**.

- [-] **D2 프롬프트 `/` 팝업**
  설정에서 템플릿을 하나 만든 뒤, 입력창에 `/` 를 친다.
  **합격**: 템플릿 목록 팝업이 뜨고, 고르면 입력창에 본문이 삽입된다.

- [P] **D3 재생성**
  답변 아래 ↻ 를 누른다.
  **합격**: 새 답변이 생성되고 **이전 답변을 대체**한다(둘이 나란히 쌓이면 실패).

- [-] **D4 편집·분기 ★**
  이전 사용자 메시지의 ✎ 로 내용을 고쳐 다시 보낸다.
  **합격**: **새 분기**가 생기고 **원본 대화도 그대로 남아** 있다.
  **추가**: 이미지가 있던 대화에서 분기했을 때 그림/다운로드 링크가 유지되는지.

- [-] **D5 프로젝트 ★**
  프로젝트를 하나 만들고(지시문 포함) 대화의 폴더를 그 프로젝트로 지정한다.
  **합격**: 그 대화의 답변에 **프로젝트 지시문이 적용**된다.
